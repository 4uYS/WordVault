快速开始

两行代码启动一台机器

browser · index.html
import { createWebOS } from './webos.js';

const os = createWebOS();
const { code, stdout } = await os.exec('uname -a');

console.log(stdout);
// Linux webos 6.6.0-webos #1 SMP x86_64 GNU/Linux
terminal
# 解压并运行测试
unzip webos-js-1.0.0.zip
cd webos-js-1.0.0
npm test

# 修改 src/ 后重新生成产物
npm run build
# → dist/webos.js (45 modules)

它包含什么

kernel · shell · userland · node

01虚拟内核

Inode VFS、挂载表、进程/信号、能力位、rlimit、SysV IPC 与内核日志。

02POSIX Shell

管道、重定向、here-doc、变量与算术展开、glob、函数、alias、作业与 trap。

03292 个命令

coreutils、grep/sed/awk、find/xargs、tar/zip、ps/top、用户管理与网络工具。

04Node.js 运行时

CommonJS + ESM、fs、path、crypto、zlib、stream、events、child_process 与 Buffer。

05系统调用

open/read/write、fork/waitpid、mount、msgget、socketpair 等 50+ 个 Linux 风格调用。

06整机快照

os.snapshot() 导出 JSON，createWebOS({ snapshot }) 在新实例中恢复文件系统与用户。
